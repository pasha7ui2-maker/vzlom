# CyberScanner

Небольшой учебный инструмент для знакомства с сетевой диагностикой и базовым аудитом HTTP-заголовков.

> Используй программу только против систем, которыми владеешь или на проверку которых у тебя есть явное разрешение. Не сканируй чужие сайты и сети.

## Возможности

- Проверка DNS-разрешения имени.
- Проверка ограниченного набора TCP-портов (без эксплуатации уязвимостей).
- Проверка доступности HTTPS и основных HTTP-заголовков безопасности.
- Понятный текстовый отчёт.

## Требования

- Python 3.10+
- Сторонние библиотеки не нужны.

## Запуск

```bash
python cyber_scanner.py example.com --authorized
```

Подставь вместо `example.com` свой домен или учебный хост, для которого у тебя есть разрешение.

Можно указать порты явно:

```bash
python cyber_scanner.py 127.0.0.1 --ports 22,80,443 --authorized
```

По умолчанию проверяются только порты 22, 80, 443, 8080 и 8443. Соединение с портом проверяется коротким TCP connect; программа не отправляет эксплойты, не подбирает пароли и не изменяет данные.

## Чему научимся

1. DNS и IP-адреса.
2. TCP и номера портов.
3. HTTPS и HTTP-заголовки.
4. Как читать результаты проверки и оформлять рекомендации.

## Ограничения

Это учебный сканер, а не полноценный пентест-инструмент. Результаты могут быть неполными: фильтрация сети, прокси и настройки сервера влияют на проверки.
