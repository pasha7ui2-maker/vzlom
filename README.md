# CyberLab

Учебная киберлаборатория с несколькими локальными инструментами и ограниченной сетевой диагностикой.

> Используй сетевую диагностику только против систем, которыми владеешь или на проверку которых у тебя есть явное разрешение. Не сканируй чужие сайты и сети.

## Возможности

### 🔎 URL-инспектор
- Анализирует подозрительные признаки в ссылках: HTTP вместо HTTPS, IP вместо домена, IDN/punycode, сокращатели ссылок, необычные порты, длинные адреса и подозрительные слова в пути.
- Работает локально: не открывает ссылку и не отправляет адрес сторонним сервисам.
- Выдаёт эвристическую оценку, а не окончательный вердикт.

### 🔐 Проверка паролей
- Проверяет длину, набор символов, повторы и простые последовательности.
- Показывает приблизительную теоретическую оценку стойкости.
- Проверка выполняется локально в памяти приложения. Пароль не отправляется в интернет и не сохраняется.
- Для обучения используй придуманные тестовые пароли, а не пароль от важного аккаунта.

### 🧬 SHA-256
- Вычисляет SHA-256 выбранного файла.
- Позволяет сравнить хеш с доверенным эталоном.
- Сохраняет текстовый отчёт о проверке.

### 🌐 Сетевой аудит
- DNS-разрешение домена.
- Ограниченная проверка TCP-портов 22, 80, 443, 8080 и 8443.
- Проверка HTTPS и основных HTTP-заголовков безопасности.
- Для запуска требуется подтверждение разрешения на тестирование.

## Запуск из исходников

Требуется Python 3.10+; сторонние библиотеки не нужны.

Запуск GUI: python cyber_scanner_gui.py

Старый CLI-сканер также сохранён. Пример: python cyber_scanner.py example.com --authorized

## EXE для Windows

Открой вкладку Releases и скачай CyberLab.exe из последней версии. Файл собирается GitHub Actions автоматически при изменении GUI или workflow.

## Ограничения

CyberLab — учебный набор утилит, а не профессиональная система защиты. URL-проверка использует эвристики и не подключается к базам репутации. Оценка пароля приблизительная и не заменяет менеджер паролей. Наличие или отсутствие HTTP-заголовка само по себе не доказывает уязвимость.
